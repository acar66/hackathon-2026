## 核心设计

**四维人格轴**

| 维度 | 色 | 含义 |
|---|---|---|
| 行动征服 | 🔴 | 主动、果断、目标导向、领导力 |
| 理性谋略 | 🔵 | 冷静、分析、规划、智商在线 |
| 自由创意 | 🟡 | 乐观、脑洞、表达、不羁 |
| 共情守护 | 🟢 | 温和、合作、守护、治愈 |

**维度签名（关键设计）**

很多人不是单一维度高，而是 3~4 个维度同时偏高，用「取最高维」或「绝对阈值」分类会把这批人粗暴归到一起。因此本项目：

1. **相对高判定** → 得出用户的「高维集合」（维度签名）
2. **签名过滤** → 候选原型 = 签名是用户高维集合子集者
3. **中心化欧氏距离** → 候选内各自减去自身四维均值再比距离，只比「哪一维相对更高」的形状

> 第 3 点解释了为什么不用绝对距离：答题每题只能给一个维度加分，20 题分摊后绝对分天然偏低，绝对距离会把用户拉向数值整体偏低的原型。

## 技术栈

- React 18 + Vite 5 + Tailwind CSS
- Canvas 像素级抠像组件：绿幕算法 + `autoKey` 自动采样背景色 + **洪水填充**（只抠与画面边缘连通的背景，主体身上的同色元素不再被误伤）+ 绿溢抑制 + 水印擦除
- 结果卡导出：html-to-image

## 本地运行

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 产出 dist/
```

纯前端静态站点，无需后端与任何密钥配置。
