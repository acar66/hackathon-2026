## 二、20 题（全新）

### A. 客观行为类（8 题，Q1–Q8）—— 真实发生过的选择，最好选、最显准

**Q1｜朋友临时约「出来聚」**
- 🔴 行动：立刻收拾出门，到了再想干嘛
- 🔵 理性：先看天气/路线/都有谁再去定
- 🟡 自由：看心情，临时换个地方也行
- 🟢 共情：先问谁去、有没有人落单需要我陪

**Q2｜刷知乎热榜时你更常**
- 🔴 行动：直接看结论和高赞，划走得快
- 🔵 理性：点进问题，多个回答交叉比对
- 🟡 自由：被脑洞标题党勾进去逛半天
- 🟢 共情：顺手给认同的回答点个赞、留句鼓励

**Q3｜接到一个陌生新任务，你第一步是**
- 🔴 行动：撸起袖子先干，边做边学
- 🔵 理性：列清单、查资料、把步骤拆清楚
- 🟡 自由：先想有没有更骚的解法/不同路子
- 🟢 共情：先想这任务对谁有影响、要不要拉人一起

**Q4｜热榜「程序员删库跑路 89TB 获刑」类新闻，你第一反应**
- 🔴 行动：这人真敢干／太莽了
- 🔵 理性：流程漏洞才是根因，不该只怪个人
- 🟡 自由：这剧情小说都不敢这么写
- 🟢 共情：他家里人要怎么办，挺唏嘘的

**Q5｜大促（双十一之类）你的真实画像是**
- 🔴 行动：看中就下单，爽就完了
- 🔵 理性：提前比价、算满减、列清单
- 🟡 自由：买点没用的小玩意儿取悦自己
- 🟢 共情：帮家人朋友一起凑单省点钱

**Q6｜一场热闹聚会结束，你更可能是**
- 🔴 行动：意犹未尽，还想续摊
- 🔵 理性：挺好但有点累，回去复盘今天认识谁
- 🟡 自由：中途溜去角落玩手机也挺自在
- 🟢 共情：临走还在帮主人收拾、送喝醉的人

**Q7｜你在知乎/朋友圈发东西，通常**
- 🔴 行动：有感就发，不纠结
- 🔵 理性：写之前先想清楚逻辑和立场
- 🟡 自由：怎么有意思怎么来，带点梗
- 🟢 共情：会考虑会不会有人看了不舒服

**Q8｜遇到"遗产归国家"那种现实麻烦，你习惯**
- 🔴 行动：先行动，找人问、跑流程
- 🔵 理性：先查规定、找案例、想清路径
- 🟡 自由：看看有没有旁门左道/奇招
- 🟢 共情：先安抚受影响人的情绪

### B. 个人偏好（3 题，Q9–Q11）

**Q9｜知乎上火的"末日重生爽文成白领安眠药"，如果真有这种文，你更想看主角走哪条线**
- 🔴 行动：杀伐果断、把仇人清算干净
- 🔵 理性：靠信息和布局逆天改命
- 🟡 自由：脑洞大开、玩转异界规则
- 🟢 共情：护住身边人一起活下去

**Q10｜你更想拥有的"超能力"是**
- 🔴 行动：绝对执行力，想到就做到
- 🔵 理性：过目不忘／推演万物
- 🟡 自由：随时能去任何想去的平行世界
- 🟢 共情：能感知别人的情绪

**Q11｜你的收藏夹里大概率有哪一类**
- 🔴 行动：实用技能／教程
- 🔵 理性：干货方法论／思维模型
- 🟡 自由：脑洞／沙雕／灵感图
- 🟢 共情：治愈／心理／人际

### C. 情绪感受（3 题，Q12–Q14）

**Q12｜知乎有句话："你测出来的人格，其实是你希望成为的自己，不是真实的你。"看到这话你第一感觉**
- 🔴 行动：管他呢，能爽就行
- 🔵 理性：有点道理，测试本就片面
- 🟡 自由：哈哈好会总结，薛定谔的人格
- 🟢 共情：那……真实的我，有人懂吗

**Q13｜什么时刻你会觉得"活着真好"**
- 🔴 行动：搞定一件难事、大汗淋漓那一刻
- 🔵 理性：想通一个困扰很久的难题
- 🟡 自由：突然冒出一个绝妙点子
- 🟢 共情：被人毫无保留地接住、理解

**Q14｜深夜 emo 刷到一条戳心回答，你通常**
- 🔴 行动：去评论区怼两句／发个动态宣泄
- 🔵 理性：截图存下，第二天理性分析为啥 emo
- 🟡 自由：顺着推荐一路逛到天亮
- 🟢 共情：转给懂的人，或默默给同类回答点赞

### D. 观念认知（3 题，Q15–Q17）

**Q15｜知乎高赞："末世的核心是秩序崩塌后活着，重点是苟住。"你对"苟"的态度**
- 🔴 行动：苟是暂时的，迟早要掀桌
- 🔵 理性：苟是最高生存智慧，蓄力待发
- 🟡 自由：苟着也要苟得快乐自由
- 🟢 共情：苟着也要拉上身边人

**Q16｜关于"公平"，你更认同哪句**
- 🔴 行动：公平是打出来的，不是等来的
- 🔵 理性：公平靠制度和规则保障
- 🟡 自由：世上本就没绝对公平，活出自己
- 🟢 共情：弱者的公平更值得被看见

**Q17｜知乎常辩"I 人 E 人"——你觉得"了解自己"主要靠**
- 🔴 行动：在事上练，做着做着就知道了
- 🔵 理性：观察反思自己的行为数据
- 🟡 自由：跟着感觉走，不被标签定义
- 🟢 共情：从别人怎么对待我、需要我中认识自己

### E. 想象倾向（3 题，Q18–Q20）

**Q18｜想象：你重生回三年前，手里有一份"未来剧本"，你第一件事**
- 🔴 行动：立刻去拦下那个错误决定／追回那个人
- 🔵 理性：先验证剧本真假，再布局三步
- 🟡 自由：拿剧本去搞点疯狂又好玩的事
- 🟢 共情：先去抱抱那时还好的家人朋友

**Q19｜末日降临，你醒来身边只有一辆改装车和三天物资，你的本能**
- 🔴 行动：马上出发，抢占高地建立据点
- 🔵 理性：先清点物资、画地图、定路线
- 🟡 自由：顺路捡奇怪装备，改造成移动城堡
- 🟢 共情：先找有没有落单的孩子／老人一起走

**Q20｜闭眼想象十年后的你，画面里最清晰的是**
- 🔴 行动：我在做成一件大事／带一支队伍
- 🔵 理性：我把生活和工作理得明明白白
- 🟡 自由：我在某个自由的地方做喜欢的事
- 🟢 共情：身边围绕着我在乎也在乎我的人

## 三、计分与落点

- **每题 4 选 1，选哪项该维 +1**；20 题做完四维分合计恒为 **20**（行动+理性+自由+共情=20）。
- 直接喂给现有 `matchArchetype(scores)` → 输出「【题材党】的【主角原型型】」+ 刘看山场景卡。
- 维度签名判定沿用已定逻辑（相对高 + 均衡高门槛），4 高/3 高人群稳稳接住。

### 四维 → 题材党·主角原型（速查 · 已用脚本实测校准）

> 下表为**实测落点**（跑了 1771 种真实作答组合 + 625 网格验证，11/11 原型全部可达），非纸面推演。

| 主导签名 | 题材党 | 主角原型型 | 组合占比 |
|---|---|---|---|
| 行动+理性+共情 | 重生复盘党 | 前世清算型 | 4.2% |
| 行动+理性 | 末世硬核党 | 硬核秩序型 | 9.4% |
| 理性+自由 | 末世硬核党 | 苟王本苟型 | 5.3% |
| 理性+共情 | 苟道飞升流 | 稳健苟道型 | 10.8% |
| 共情为主 | 甜宠守护党 | 温柔兜底型 | 18.8% |
| 理性+自由（真相向） | 真相解构党 | 真相解构型 | 8.2% |
| 行动+理性+自由 | 独立搞钱党 | 搞钱女王型 | 6.9% |
| 自由+共情 | 烟火守艺党 | 烟火守艺型 | 12.4% |
| 行动+自由 | 末世硬核党 | 疯批爆裂型 | 7.6% |
| 四维均衡 | 独立搞钱党 | 全能操盘型 | 7.8% |

**单维极端时的兜底**（没有原型只靠单一维度定义，走全池最近）：
- 纯行动 → 硬核秩序型；纯理性 → 历史操盘型；纯自由 → 疯批爆裂型；纯共情 → 温柔兜底型。

**与原纸面表的两处修正（已确认保留实现侧口径）**：
1. 「理性+共情」原写历史操盘型，实测为**稳健苟道型**——因为历史操盘型签名是 `行动+理性`（谋士需要执行力落地布局），而稳健苟道型签名正是 `理性+共情`（自保+护身边人），以后者为准。
2. 「自由+共情」需命中烟火守艺型，故其签名由 `共情` 修正为 `自由+共情`（原与温柔兜底型签名字面上撞车，导致两者无法区分）。
