# 主角原型 · 知乎风命名提案（v1）

> 配套《题材分类-知乎风命名提案.md》使用。
> 体系：题材桶 = 「党/流」（你属于哪个阵营）；主角原型 = 「型」（你本命是哪个角色）。
> 8 个题材桶名称沿用上一版，本文件只重命名 **10 个主角原型**。

---

## 命名规则

- 统一后缀 **「型」**：贴合知乎人格测试/MBTI 语境，截图分享天然顺口（"我是 XX 型"）。
- 内核尽量保留原型的标志性名词（复仇、列车长、苟王、谋主…），再用知乎黑话润色：
  - **搞钱 / 操盘 / 兜底 / 清算 / 稳健 / 硬核 / 解构 / 烟火** 均为知乎高频词，保证平台味。
- 每张卡：推荐名 + 原名对照 + 主导心相 + 映射题材党 + 命名思路 + 备选。

## 备选池（若不想统一"型"字）

- 用 **「本 X」** 体系（更俏皮）：前世清算本王 / 苟王本苟 / 搞钱本王 / 疯批本神
- 用 **「选手」** 体系（更轻松）：复仇选手 / 列车长选手 / 苟王选手 / 搞钱选手
- 用 **「天花板」** 体系（更夸张）：清醒复仇天花板 / 搞钱天花板 / 稳健悟道天花板

## 与题材桶的衔接示例

> 测出四维：行动 88 / 理性 72 / 自由 78 / 共情 44
> → 阵营归属：**独立搞钱党**（大女主/事业）
> → 本命主角原型：**搞钱女王型**
