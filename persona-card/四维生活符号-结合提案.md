# 四维 × 生活符号 结合提案（v1）

> 问题：四维（行动红 / 理性蓝 / 自由黄 / 共情绿）目前只用于"打分→匹配 1 个原型"，用得太少。
> 方案：① 把四维锚定到日常可感的生活符号（咖啡、裙子…），让测试有画面、结果卡可截图；
>       ② 处理"有人 4 维都高 / 3 维高"——用**多高维组合**而非只取最高 1 维。

---

## 一、生活符号 × 四维映射（先落地"咖啡 + 裙子"）

### ☕ 咖啡 → 维度
| 你常点的 | 对应维度 | 为什么 |
|---|---|---|
| 冰美式 / 无糖黑咖 | 行动红 | 直给、提神、不绕弯，干活冲就完事 |
| 手冲单品 / 瑰夏 | 理性蓝 | 讲究参数、钻研风味，慢工出细活 |
| 冷萃 / 气泡美式 | 自由黄 | 清爽反套路，脑洞型选手 |
| 燕麦拿铁 / 热拿铁 | 共情绿 | 温柔治愈，暖到自己也给别人 |
| 焦糖玛奇朵 / 星冰乐 | 自由黄 | 花哨爱玩，甜系不羁 |
| 馥芮白 / 卡布奇诺 | 理性蓝 | 层次讲究，知性派 |

### 👗 裙子 → 维度
| 你衣柜里的 | 对应维度 | 为什么 |
|---|---|---|
| 西装裙 / 包臀裙 | 行动红 | 干练掌控，气场拉满 |
| 极简缎面 / 衬衫裙 | 理性蓝 | 知性高级，less is more |
| 不规则剪裁 / 破洞吊带 | 自由黄 | 不羁脑洞，拒绝模板 |
| A字碎花 / 针织裙 | 共情绿 | 温柔治愈，邻家感 |

> 每个符号都带一句"知乎风"文案，结果卡可写：「你的灵魂饮品是冰美式，灵魂裙装是西装裙——行动红 × 行动红，纯血行动派。」

## 三、多高维组合（解决"4 维都高 / 3 维高"）
不再只取最高 1 维，按"分数前 N 高且差距 < 阈值(如 12 分)"取组合，给复合人格名：

| 组合 | 复合标签 | 一句话 |
|---|---|---|
| 红+蓝 | 谋定后动派 | 想清楚再冲，冲就冲赢 |
| 红+黄 | 燃系玩家 | 又猛又有梗，全场最炸 |
| 红+绿 | 领路人 | 带队冲，也护队友 |
| 蓝+黄 | 脑洞策士 | 分析+创意双开，方案最骚 |
| 蓝+绿 | 温柔智者 | 冷静但共情，靠谱又暖 |
| 黄+绿 | 治愈艺术家 | 不羁的外壳，柔软的内核 |
| 红+蓝+黄 | 三栖全能王 | 想得透、玩得花、干得狠 |
| 红+蓝+绿 | 稳健操盘手 | 冲得动、算得准、护得住 |
| 四高 | 全息人格 | 四相俱全，集大成者 |

> 结果卡层级：① 题材党（8 选 1）→ ② 多高维复合标签 → ③ 本命主角原型（10 选 1）。
> 例：「重生复盘党 · 三栖全能王 · 本命【搞钱女王型】」
