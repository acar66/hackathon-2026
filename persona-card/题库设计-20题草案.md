# 知乎人格卡 · 20 题题库草案（待确认）

> 设计原则（来自你的要求）：
> 1. **客观行为类问题多一点**——真实、好选、确定性强，让人觉得"测得准"。
> 2. **四类体验均覆盖**：个人偏好 / 情绪感受 / 观念认知 / 想象倾向，各 2–3 道。
> 3. **尽量调动感受、有代入感**：用"联系生活 / 唤起回忆 / 闭眼想象"等方式牵引情绪。
>
> 计分方式：每题 4 个选项，分别对应 **行动红 / 理性蓝 / 自由黄 / 共情绿** 四维度之一，
> 选哪个就给对应维度 +1（或加权）。20 题做完得到四维分，喂给 `matchArchetype` 出「【党】的【型】」。

## 一、客观行为类（8 道）— 真实场景，选"你真的会怎么做"

**Q1. 周末朋友临时约你去一座完全陌生的城市玩两天，你第一反应是？**
- A. 立刻收拾出发，到了再说 → 行动
- B. 先查攻略、做预算和行程表 → 理性
- C. 不去景点，想随便走走找点奇怪小店 → 自由
- D. 担心朋友会不会不方便，先问大家意见 → 共情

**Q2. 你负责的小项目突然出了岔子，deadline 就在明天，你会？**
- A. 撸起袖子通宵也要把它干完 → 行动
- B. 先冷静拆解问题，按优先级逐个解决 → 理性
- C. 试试平时没用过的野路子解法 → 自由
- D. 先安抚被波及的队友情绪，再一起扛 → 共情

**Q3. 群里有人发了个你完全看不懂但很火的新梗，你会？**
- A. 直接用起来，管它什么意思 → 行动
- B. 搜一下起源和语境再决定要不要玩 → 理性
- C. 自己造个更离谱的版本发回去 → 自由
- D. 看看大家是不是都在玩，别显得自己落伍 → 共情

**Q4. 你点外卖 / 买东西时更常出现哪种情况？**
- A. 看准就下单，不喜欢纠结 → 行动
- B. 反复比参数、看测评才下单 → 理性
- C. 被好看的包装 / 创意种草就买 → 自由
- D. 想到爸妈 / 室友喜不喜欢也捎一份 → 共情

**Q5. 回忆一下，上次你"怼"人或"硬刚"，是因为？**（唤起回忆）
- A. 对方挡了我要做的事 / 触了我底线 → 行动
- B. 对方逻辑有问题、胡说八道 → 理性
- C. 对方太无趣 / 墨守成规让我烦 → 自由
- D. 对方在欺负弱小 / 让我朋友受委屈 → 共情

**Q6. 遇到一个完全没接触过的新技能（剪辑 / 做饭 / 编程…），你通常？**
- A. 直接上手瞎搞，做出来再说 → 行动
- B. 先看系统教程再练 → 理性
- C. 边玩边改，搞出自己的风格 → 自由
- D. 拉个朋友一起学，互相打气 → 共情

**Q7. 出门旅行你更可能是？**
- A. 那个催大家"快点走啦"的人 → 行动
- B. 那个拿着地图安排路线的人 → 理性
- C. 那个走到哪算哪、专找冷门的人 → 自由
- D. 那个记得给 everyone 带水带药的人 → 共情

**Q8. 你手机相册 / 收藏里最多的是？**
- A. 各种"待办 / 截图 / 战绩" → 行动
- B. 资料 / 笔记 / 对比表 → 理性
- C. 脑洞图 / 表情包 / 灵感 → 自由
- D. 和人的合照 / 聊天记录 → 共情

## 二、个人偏好（3 道）

**Q9. 只能带一样东西去荒岛一个月，你选？**
- A. 一把多功能工具刀 → 行动
- B. 一本生存百科全书 → 理性
- C. 一把吉他 / 画板 → 自由
- D. 一只靠谱的狗 / 一个挚友 → 共情

**Q10. 你更吃哪种人设（小说 / 剧 / 现实都算）？**
- A. 杀伐果断、一路开挂的 → 行动
- B. 运筹帷幄、智商在线的 → 理性
- C. 不按套路出牌的怪才 → 自由
- D. 温柔可靠、把人放在心上的 → 共情

**Q11. 你理想的周末下午是？**
- A. 去攀岩 / 打球 / 搞点刺激运动 → 行动
- B. 泡图书馆 / 钻研一个爱好 → 理性
- C. 发呆、乱涂乱画、做白日梦 → 自由
- D. 和朋友窝着聊天嗑瓜子 → 共情

## 三、情绪感受（3 道）— 牵引情绪

**Q12. 什么时候你会觉得"最爽 / 最有成就感"？**
- A. 把一件难事硬啃下来的那一刻 → 行动
- B. 想通一个卡了很久的难题 → 理性
- C. 灵光一现想出超绝点子 → 自由
- D. 看到身边人因为你而开心 → 共情

**Q13. 你更容易被什么戳中泪点？**
- A. 逆袭翻盘、绝地反击的瞬间 → 行动
- B. 一个人默默扛下所有的孤独 → 理性
- C. 不被理解的天才终于被看见 → 自由
- D. 平凡人之间互相托底的温柔 → 共情

**Q14. 压力大到爆的时候，你身体 / 心里最先反应是？**
- A. 坐不住，想直接干点什么 → 行动
- B. 开始列清单、分析压力源 → 理性
- C. 想逃开，做点没用但开心的事 → 自由
- D. 想找人聊聊，或担心拖累别人 → 共情

## 四、观念认知（3 道）

**Q15. 你觉得"靠谱"最重要的是？**
- A. 说到做到、遇事不怂 → 行动
- B. 想得周全、少出岔子 → 理性
- C. 有想法、不随大流 → 自由
- D. 替别人着想、让人安心 → 共情

**Q16. 对于"人生要不要留后路"，你更认同？**
- A. 干就完了，后路是给怂人的 → 行动
- B. 必须留，兵法中叫"奇正相生" → 理性
- C. 不留，但我会走一条没人走过的 → 自由
- D. 后路是给家人的，不是给自己的 → 共情

**Q17. 你眼里的"成功"更接近？**
- A. 拿结果、赢、被看见 → 行动
- B. 把事想透、做对选择 → 理性
- C. 活出独一无二的自己 → 自由
- D. 身边的人都被我照顾得挺好 → 共情

## 五、想象倾向（3 道）— 闭眼想象，强代入

**Q18. 假如给你一次"重生"机会回到 18 岁，你第一件事是？**
- A. 把当年怂了没做的事全做了 → 行动
- B. 重新规划专业和人生路线 → 理性
- C. 学一门完全没碰过的艺术 → 自由
- D. 早点出现在某个重要的人身边 → 共情

**Q19. 如果世界突然进入"物资紧缺的末日"，你觉得自己会？**
- A. 冲出去找资源、组队守地盘 → 行动
- B. 建一套分配和防御的规矩 → 理性
- C. 躲起来，靠脑洞和手艺苟住 → 自由
- D. 先把老弱安顿好再说 → 共情

**Q20. 闭上眼睛想象"十年后的自己"，画面里最可能有？**
- A. 一个在台上 / 场上发光的人 → 行动
- B. 一个把生活安排得明明白白的人 → 理性
- C. 一个在远方 / 未知里自由的人 → 自由
- D. 一群围着你的、笑的人 → 共情
