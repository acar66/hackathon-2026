# 跨次元游乐场 · 知乎人格卡

> 知乎黑客松 2026｜校园新锐季 · 赛道：🧠 灵魂匹配局（社区连接与兴趣社交）
>
> 用 20 道取材于知乎真实热榜与高赞讨论的情境题，测出你的四维人格签名，映射到「8 大题材党 × 11 种主角原型」，生成一张可分享的专属人格卡——配知乎官方 IP 刘看山的定制场景。

---

## 一、项目一句话

**在知乎，你是什么"党"的什么"型"？**

答完 20 道题，你会得到一张写着「【末世硬核党】的【硬核秩序型】」的人格卡，配上属于你的刘看山形象、代表性角色与高光片段——可以一键保存分享，天然适合在社区里引发"你是什么型"的讨论。

---

## 二、创作思路：为什么做这个

### 1. 洞察：知乎用户的身份认同，来自"内容偏好"而不是"心理量表"

传统人格测试问的是"你是否喜欢独处"这类抽象问题，与知乎用户的真实行为脱节。而在知乎，一个人的身份其实写在他的行为里：他怎么刷热榜、收藏夹里囤什么、深夜 emo 时做什么、看到争议新闻的第一反应是什么。

**所以我们的题目全部锚定知乎真实场景**——让用户一看就觉得"这说的不就是我刷到的那条"。

### 2. 桥梁：把知乎最火的网文题材变成人格容器

知乎盐选与社区讨论中，重生、末世、穿越、苟道、甜宠、悬疑、搞钱、种田是八大高频题材。我们把它们做成 8 个"党"，每个党下面再细分"主角原型"（型）。

这样测试结果的语义从"你是 INTJ"变成了**"你是末世硬核党的硬核秩序型"**——更有画面感、更年轻化、更适合传播。用户会主动晒、会追问"你是什么型"，形成社区内的自然裂变。

### 3. 差异化：不是又一份人格测试，而是"知乎内容 × 网文题材 × 社区 IP"的三重映射

| 常规人格测试 | 本项目 |
|---|---|
| 题目抽象、与平台无关 | 题目来自知乎真实热榜与高赞讨论 |
| 结果是 4 个字母 | 结果是「党 + 型 + 代表角色 + 高光片段 + 刘看山形象」 |
| 视觉是文字报告 | 视觉是卡片 + 知乎官方 IP 定制场景 |

## 三、核心设计：四维 → 维度签名 → 党 · 型

### 1. 四维人格轴

| 维度 | 色 | 含义 |
|---|---|---|
| 行动征服 | 🔴 红 | 主动、果断、目标导向、领导力 |
| 理性谋略 | 🔵 蓝 | 冷静、分析、规划、智商在线 |
| 自由创意 | 🟡 黄 | 乐观、脑洞、表达、不羁 |
| 共情守护 | 🟢 绿 | 温和、合作、守护、治愈 |

### 2. 关键设计：用「维度签名」而不是「绝对分数」分类

这是本项目在算法上最重要的一处原创设计。

**问题**：实践中发现很多人不是单一维度高，而是 3 个甚至 4 个维度同时偏高。若用传统的"取最高维度"或"绝对阈值 65"来分类，这批人会被粗暴归到同一类，分类区分度严重不足。

**解法**：把四维分数转成**维度签名**（哪些维度相对为高），再用"签名子集匹配 + 形状距离"定位原型：

1. **相对高判定**：先判是否"均衡且整体中高"（极差 ≤ 18 且均值 ≥ 55）→ 是则判为全高（接住 3 高/4 高人群）；否则取自身区间上半部为高。这样判定的是"你哪几项相对更强"，而非绝对分数。
2. **签名过滤**：候选原型 = 签名是用户高维集合子集的那些（如"行动+理性+共情" → 前世清算型）。
3. **中心化欧氏距离**：候选内各自减去自身四维均值再比距离，**只比"哪一维相对更高"的形状**。

> 第 3 点是一处必要的工程修正。答题每题只能给一个维度加分，20 题分摊后绝对分天然偏低（三高各 6~7 题仅约 46 分），若直接比绝对距离，用户会被拉向数值整体偏低的原型。中心化后，"行动+理性+共情"的用户能正确落在前世清算型，而不是被误判为其他型。

### 3. 覆盖验证（可复现）

写了校验脚本 `scripts/check-quiz.mjs`，跑两类空间：

- **答题真实空间**：20 题每题选一维 → 四维命中次数满足 `a+r+f+c=20`，共 **1771 种**组合
- **连续空间**（滑块调试模式）：5⁴ = **625** 网格

**两个空间均 11/11 原型可达**，占比分布 4.2% ~ 18.8%，无死原型、无过度集中。

## 四、与知乎社区生态的契合度（重点）

### 1. 题目情境全部来自知乎真实内容

通过知乎开放平台能力（本地 CLI 实跑站内搜索与热榜）拉取真实内容作为命题素材，并在题目中标注题源：

| 题源 | 用到的题 |
|---|---|
| 热榜：程序员删光 89TB 数据获刑 | Q4（你的第一反应） |
| 热议：独居者离世无继承人、房产归国家 | Q8（现实麻烦怎么处理） |
| 高赞：末日重生爽文成当代白领安眠药 | Q9、Q15、Q18、Q19 |
| 讨论：MBTI「薛定谔的人格」 | Q12、Q17 |
| 热议：I 人 / E 人聚会后需要恢复空间 | Q6、Q17 |
| 社区习惯：收藏夹分门别类文化 | Q11 |
| 知乎经典体：「如果给你一次重生机会」 | Q1、Q18 |

用户在答题时会反复产生"这不就是我昨天刷到的那条"的熟悉感——这是沉浸感的来源，也是本项目区别于通用测试的核心。

### 2. 结果角色来自社区高频讨论的真实作品

每个原型配 3 位可核验的代表角色（如《重生之将门毒后》沈娇娇、《庆余年》范闲、《我师兄实在太稳健了》李长寿等），并附**高光片段**——点击原型名即可展开一段有画面感的文字，强化"这就是我"的代入。

### 4. 赛道契合

本作对应 **🧠 灵魂匹配局：社区连接与兴趣社交**——官方描述中的方向"基于兴趣、观点与内容行为的同好匹配工具""围绕话题、回答、收藏、关注关系构建的轻量互动体验"正是本项目的定位：

- 用**内容行为**（怎么刷热榜、收藏什么、怎么写回答）推断人格，而非自陈量表
- 产出的「党 · 型」是天然的社区谈资与同好识别暗号（"同党"即可展开讨论）
- 卡片可保存分享，是社区内轻量互动的载体

## 五、技术实现方案

| 层 | 选型 / 做法 |
|---|---|
| 框架 | React 18 + Vite 5 + Tailwind CSS |
| 状态与流程 | 自管理三阶段状态机：开始页 → 单题逐答（20 题）→ 结果卡 |
| 答题体验 | 单题逐答 + 进度条 + 分组提示（客观行为/偏好/情绪/认知/想象）+ 题号点阵回跳 |
| 防位置偏差 | 选项按题目 id 做**确定性洗牌**（同一题顺序稳定、返回不跳变），计分靠维度字段与显示顺序解耦 |
| 图像处理 | Canvas 像素级抠像组件：默认绿幕算法（绿色通道相对优势 + 绿溢抑制）；`autoKey` 模式自动采样四角推断背景色，可处理青绿/蓝/灰等纯色背景；支持按图单独调 `tolerance/edge/spill`；右下角水印区域擦除 |
| 分类算法 | 维度签名过滤 + 中心化欧氏距离（见第三节） |
| 结果导出 | html-to-image，一键保存卡片为图片 |
| 工程验证 | `scripts/check-quiz.mjs`：13 种典型作答落点 + 1771 组合 + 625 网格覆盖验证 |

### 题目结构（20 题）

| 分组 | 题数 | 测什么 |
|---|---|---|
| 客观行为 | 8 | 你真实会怎么做（最易作答、最显准） |
| 个人偏好 | 3 | 你天然被什么吸引 |
| 情绪感受 | 3 | 什么会真的戳到你 |
| 观念认知 | 3 | 你相信什么 |
| 想象倾向 | 3 | 你的本能会往哪走 |

计分：每题 4 选 1，选中项对应维度 +1；映射公式 `20 + (命中数/20)×75`，落在 20~95，与原型画像同量纲。

## 六、项目亮点小结

1. **算法原创**：维度签名机制专门解决"多维同高"人群的分类失效，并配可复现的覆盖验证脚本。
2. **内容真实**：题目、角色、IP 全部扎根知乎真实内容与官方资产，不是凭空编造的通用题。
3. **体验完整**：从答题、进度反馈、高光展开、刘看山场景到卡片导出，是一条走得通的完整链路。
4. **传播友好**：结果语义年轻化（「党」+「型」），配图可保存，天然适合社区讨论与二次传播。
